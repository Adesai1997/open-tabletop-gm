# Full-text corpus note

The private distribution of this skill bundles the complete text of the
source library under `fulltext/` (including `fulltext/rulebooks/` with the
SRD and the owner's rulebook library). Copyrighted rulebook texts are
excluded from this public repository; only the open-licensed SRD data
(`skills/dnd/data/srd-2014/`) and distilled, source-cited lore references
are published here. Drop your own documents into `fulltext/` to extend
the lorebook (see `lore/INDEX.md`).
